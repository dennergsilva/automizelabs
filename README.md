# AutomizeLabs

Landing page institucional da **AutomizeLabs** — consultoria de automação, inteligência artificial e integração de sistemas.

**🔗 Site:** https://dennergsilva.github.io/automizelabs/

## Stack

- HTML5 semântico
- CSS puro (variáveis CSS, grid, animações)
- JavaScript vanilla (sem frameworks)
- Hospedado em GitHub Pages

## Estrutura

```
automizelabs/
├── index.html       Landing principal
├── styles.css       Estilo cyberpunk neon
├── script.js        Animações, partículas, efeitos
└── .nojekyll        Desabilita processamento Jekyll
```

## Rodar localmente

Qualquer servidor estático serve. Exemplo com Python:

```bash
python -m http.server 8000
```

Depois abra http://localhost:8000
